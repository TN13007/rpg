# Adventurer Academy — UI Prototype

A text-first fantasy life simulation UI prototype built with Godot 4.7 .NET and C#.

## Run
1. Open `project.godot` in Godot 4.7 .NET.
2. Build the C# project when prompted.
3. Run the project (F6/F5).

## Prototype controls
- Use the left sidebar to switch between Explore, Map, Profile, Relationships, Inventory, Quests, Skills and Settings.
- In Explore, select a person or object to view its shared identity / description / state / actions panel.
- Use connected exits to move between locations. Map travel is restricted to adjacent locations.
- Interactions are prototype state changes; this is not the full Sprint 1 gameplay implementation.

## Current scope
- Academy and training-dungeon locations.
- Consistent location content sections: scene, people, objects and exits.
- Shared contextual interaction panel for all selectable entities.
- Basic demo actions for quest, hygiene, combat and day transition.
