# RPG — Adventurer Academy

Godot 4.7.2 .NET / C# project.

Adventurer Academy is a player-directed fantasy life-simulation RPG. Daily life, relationships, exploration, adventures and tactical combat are connected ways of interacting with one continuing world. Combat has its own specialized tactical rules; its outcomes belong to the wider character and world experience.

## Run the project

Open the repository in Godot 4.7.2 .NET and run `Scenes/Main.tscn`.

For automated validation, follow the single command in [CONTRIBUTING.md](CONTRIBUTING.md#7-one-command-validation). Godot runtime and player-journey checks are additional manual verification.

## Documentation rule

Design defines the intended experience. Implementation describes the current code and technical contracts. They must not be edited to pretend they already agree: record the gap and resolve it through an Issue and reviewed change. Historical material lives in [Docs/Archive](Docs/Archive/README.md) and is not active guidance.
