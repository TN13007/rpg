## Reading rules

- This folder describes intended design, not necessarily implemented behavior.
- Each document labels decisions as **Accepted**, **Proposed** or **Open** where that distinction matters.
- An accepted design decision does not imply that code exists.
- Numeric values remain provisional until validated in a playable encounter.
- Do not put class names, file paths, service ownership, data schemas or code flows here. Those belong in [Implementation Documentation](../Implementation/README.md).
- Do not duplicate project status or session progress here. [WORKFLOW.md](../../WORKFLOW.md) owns the changing implementation handoff.
