## Design status

- **Accepted** means a direction or rule has been chosen.
- **Proposed** means a candidate that still needs validation or approval.
- **Open** means no decision has been made.
- Numeric values remain provisional until tested in a playable encounter.

A decision recorded here does not mean it is implemented. Implementation reality belongs in [Implementation](../Implementation/README.md). Current work and status belong in [WORKFLOW.md](../../WORKFLOW.md).

## Change design

Use a GitHub Issue with the Design template when a meaningful decision is unresolved. Once decided, update the owning document here and close the Issue with a link to the decision. Do not create a separate document for every idea, meeting or design question.
